## 简介

本 Skill 为职业院校教师自动生成符合"三段10分钟"认知科学方法的 40 分钟课堂教学设计（教案）。根据班级学情自动选择统一型或分层型模板，输出结构化的 Markdown 文件以及可直接打印/提交的 Word 文档。

> **核心理念**：岗位导向 → 认知节奏 → 保底拔高。每一份教案都回答三个问题：
> 1. 这堂课学生在什么岗位场景下用到这个知识？
> 2. 40 分钟如何贴合职业院校学生的注意力曲线？
> 3. 最弱的学生带走什么？最强的学生还能吃到什么？

## 教案结构（21 字段）

| # | 字段 | 说明 |
|---|------|------|
| 1-9 | **基础信息** | 课程名称、课题、班级、人数、学段、教育类型、教材、课时、课型 |
| 10 | 教学目标 | 知识/技能/素养三目标，使用可观测行为动词 |
| 11 | 学情分析 | 知识储备、能力基础、学习风格 |
| 12-13 | 教学/学习方法 | 根据课型自动推荐 |
| 14-15 | 教学重点及解决措施 / 教学难点及突破措施 | 每条重点/难点配解决/突破措施 |
| 16 | 教学资源 | 设备、工具、软件、资料 |
| 17 | 教学思路 | 理念选型、策略依据、课程目标关系 |
| 18 | **教学流程** | 三段式核心：破冰筑基→重难点攻坚→落地实操 |
| 19 | 评价设计 | 量规表，分层版含双标准分值 |
| 20 | 板书设计 | 主板书+副板书+布局示意 |
| 21 | 教学反思 | （课后填写占位） |

### 教学流程时间结构

```
10min 模块一（破冰筑基）
  ├─ 0-2min  导入锚定（真实企业场景）
  ├─ 2-8min  核心授课（1个基础知识点，不延伸）
  └─ 8-10min 小结提问
 3min 缓冲一（不讲新知识：段子/提问/复盘）
10min 模块二（重难点攻坚）
  ├─ 13-15min 衔接与价值锚定
  ├─ 15-21min 重难点精讲（1个核心难点）
  └─ 21-23min 深度提问
 3min 缓冲二（不讲新知识：互测/梳理/提问）
10min 模块三（落地实操）
  ├─ 26-28min 知识串联
  ├─ 28-34min 案例实操（分层任务）
  └─ 34-36min 分层梳理
 4min 终局复盘 + 课后任务 + 答疑
────────────────────────────
40min 总计
```

## 模板说明

| 模板 | 适用场景 | 特征 |
|------|---------|------|
| **统一型** (`references/uniform-template.md`) | 学生水平基本一致 | 4列表格，无分层标注，教学目标统一 |
| **分层型** (`references/layered-template.md`) | 存在明显分层/两极分化 | 5列表格（含分层标注列），双目标/双评价标准 |

学情描述中包含"分层""混课时""基础弱""两极分化""一部分…另一部分"等关键词时，自动触发分层模板。

## 安装与依赖

本 Skill 为 OpenCode 技能包，放入 OpenCode 的 skills 目录即可使用。

生成 DOCX 时需要以下 Python 库：

```bash
pip install python-docx
```

处理参考材料时的可选依赖：

```bash
pip install pdfplumber PyMuPDF pytesseract Pillow
```
