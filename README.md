# teaching-plan-generator

> 40 分钟三段式课堂教案生成技能——输入课程信息或参考材料，输出 **MD + DOCX** 双格式教学设计，适配职业院校（中职/高职）统一型与分层型两种学情。

本仓库是一个 **Agent 技能包**（供 Codex / Claude Code 等编码智能体加载使用），不是独立应用。

## 功能特性

- **三段式教学流程**：筑基（10min）→ 攻坚（10min）→ 实操（10min），配 3min 缓冲段与 4min 终局复盘，严格 40 分钟闭环
- **双学情模板**：根据学情描述自动选择统一型（4 列表格）或分层型（5 列表格 + 基础/进阶双目标双标准）
- **参考材料解析**：支持 PDF / DOCX / MD / TXT / 图片 OCR，自动预填课程信息、教材、目标候选等字段
- **质量硬约束**：21 个字段完整生成、可观测行为动词、时间公式校验、占位符零残留，输出前逐项自检
- **统一 DOCX 版式**：基础信息表 + 12 章节（学情分析在教学目标前），页脚页码、黑体标题、表头底纹，样式规范入库
- **岗位导向开场**：导入环节必须锚定真实企业/岗位场景，拒绝"今天我们学习……"式空泛开场

## 快速开始

在支持 Agent 技能的客户端（如 Codex、Claude Code）中引入本技能，然后用自然语言发起：

> 帮我生成一份教案：《汽车发动机构造与维修》"发动机怠速不稳的故障诊断"，
> 2025 级汽修 2 班 35 人，中职二年级，实操技能课，
> 班上学情两极分化，大约 60% 基础 / 40% 进阶。

技能会自动：

1. 收集/确认 9 项参数（课程名称、课题名称、班级、人数、学段、教育类型、教材、课时、授课类型）
2. 按学情关键词判断模板类型，分层时追问比例
3. 生成教案 MD 预览 → 教师确认 → 输出 `MD + DOCX`

输出文件名：`[课程名称]_[课题名称]_教学设计.md` / `.docx`

## 使用场景

| 场景 | 说明 |
|------|------|
| 日常备课 | 提供课程信息，快速产出规范教案 |
| 公开课 / 比赛课 | 强调设计意图与评价量规，逐分钟教学流程表格 |
| 分层教学 | 学情差异大的班级，自动生成分层标注与双标准评价 |
| 材料转教案 | 提供课程内容文档、已有教案、企业岗位手册作为参考，自动预填 |

## 教学流程结构

```
10 (模块一·破冰筑基) + 3 (缓冲) + 10 (模块二·重难点攻坚)
+ 3 (缓冲) + 10 (模块三·落地实操) + 4 (终局复盘) = 40 min
```

- 模块一：真实企业场景导入 + 1 个基础概念/操作框架
- 模块二：1 个核心难点/易错点精讲 + 开放探究
- 模块三：案例实操/错题拆解/技能模拟
- 缓冲段不讲新知识（随机提问 / 行业小段子 / 同桌互测等三选一）

## 参考材料支持

| 格式 | 解析方式 |
|------|---------|
| PDF | `pypdf`（首选），失败时 `PyMuPDF` |
| DOCX | `python-docx` |
| MD / TXT | 直接读取 |
| 图片 (JPG/PNG) | `pytesseract` + `Pillow`（需本地 Tesseract 引擎） |

支持三种材料类型：课程内容文档（A）、已有教案参考（B）、企业岗位手册（C），多材料冲突时列出候选并标注推荐项。

## 依赖

| 包 | 用途 | 安装 |
|----|------|------|
| `python-docx` | DOCX 生成 + DOCX 材料读取（必需） | `pip install python-docx` |
| `pypdf` | PDF 材料提取（首选，纯 Python 轻量） | `pip install pypdf` |
| `PyMuPDF` | PDF 提取备选（仅 pypdf 失败时安装） | `pip install PyMuPDF` |
| `pytesseract` | 图片 OCR（需 Tesseract 引擎） | `pip install pytesseract` |
| `Pillow` | 图片预处理 | `pip install Pillow` |

## 仓库结构

```
teaching-plan-generator/
├── SKILL.md                          # 技能定义（唯一事实源）：工作流、字段规则、质量清单
├── AGENTS.md                         # 仓库导览与约定
├── references/
│   ├── uniform-template.md           # 统一学情模板（4 列表格）
│   ├── layered-template.md           # 分层学情模板（5 列表格，含分层标注）
│   └── docx-style-spec.md            # DOCX 样式规范（页面/字体/表格/页码）
└── scripts/
    └── generate_docx.py              # DOCX 生成脚本（仅通过 JSON 调用）
```

## 输出结构说明

- **MD**：21 个编号字段（十 学情分析 → 十一 教学目标 → … → 二十一 教学反思）
- **DOCX**：无编号基础信息表（9 行 × 2 列）+ 12 个 Heading 1 章节（一 学情分析 → 十二 教学反思）；版式遵循 `references/docx-style-spec.md`

## 开发约定

- 交互与输出一律使用中文
- `SKILL.md` 是唯一事实源，规则变更以它为准
- `scripts/generate_docx.py` 不得重写，只通过 JSON 文件调用
- 临时 JSON 在 DOCX 生成成功后立即删除
- 模板占位符 `{Mustache}` 语法，`{#each}...{/each}` 为可重复区块
