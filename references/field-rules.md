# Field Generation Rules（逐字段生成规则）

> Step 3 **MANDATORY** 整读本文件后生成；字段数量与顺序**以 Step 2 所加载模板为唯一事实源**。与模板冲突时以模板为准。

按以下顺序逐字段生成。

## 字段 1-9: 基础信息
直接填入教师确认后的值。第 8 教学课时默认 1课时/40分钟。

## 字段 10: 学情分析
基于教师描述的学情推断三项：

- **知识储备**：已学相关课程/知识基础
- **能力基础**：已掌握的技能/实操水平
- **学习风格**：学习习惯/偏好/常见问题

分层版额外注明："本班学情分层：基础学生约占 X%，进阶学生约占 Y%"

## 字段 11: 教学目标
使用 **ABCD 法 + SMART 原则**，对齐"保底拔高"理念——先写出最弱学生必须达到的下限，再向上拉伸上限。生成三项子目标：

- **知识目标**：学生能说出/列举/描述/解释...（可观测认知动词，禁止使用"了解""知道""掌握"等模糊动词）
- **技能目标**：学生能操作/完成/诊断/设计...（可观测行为动词）
- **素养目标**：培养/树立/增强...意识/习惯/态度

分层版额外拆分：
```
**基础目标**（全体学生达到）
  - 知识：...
  - 技能：...
  - 素养：...
**进阶目标**（深度学习学生达到）
  - 知识：...
  - 技能：...
  - 素养：...
```

## 字段 12-13: 教学方法与学习方法
基于授课类型自动推荐：

| 授课类型 | 推荐教学方法 | 推荐学习方法 |
|----------|-------------|-------------|
| 理论新课 | 案例教学法、讲授法 | 笔记整理、思维导图 |
| 实操技能课 | 任务驱动法、演示法 | 小组协作、实操练习 |
| 复习考核课 | 练习法、讨论法 | 自查互测、错题整理 |

若教师提供了已有教案参考（B 类材料），优先模仿其教学风格。

## 字段 14-15: 教学重点及解决措施 / 教学难点及突破措施
对齐"岗位导向"理念——每个重点之所以是重点，是因为它在岗位实操中最常用或出错代价最高；每个难点之所以是难点，是因为学生缺少对应的岗位经验。格式：

```
**教学重点**
1. XXX —— 解决措施：XXX
2. XXX —— 解决措施：XXX

**教学难点**
1. XXX —— 突破措施：XXX
2. XXX —— 突破措施：XXX
```

## 字段 16: 教学资源
按类别列出所需资源：

- 设备：...
- 工具/仪器：...
- 软件/平台：...
- 资料/文档：...

## 字段 17: 教学思路
阐述本课的教学理念与策略（偏理论层面，不与教学流程重复）。2-3 段，包含：教学理念选型、策略设计依据、与课程目标的关系。

## 字段 18: 教学流程
核心字段，严格按 SKILL.md §教学流程结构速览 生成。对齐"认知节奏"理念——每个模块的时间分配贴合职业院校学生的注意力波峰/波谷（开场抓注意→中段攻坚→末段实操），不是随意切分。

## 字段 19: 评价设计
对齐"保底拔高"理念——评价不是一刀切的尺子，而是基础生和进阶生用不同的尺子量。生成评价量规表：

| 评价维度 | 评价指标 | 评价标准（分值） | 评价主体 | 评价方式 |
|----------|---------|-----------------|---------|---------|
| 学习态度 | （动态，如出勤、专注度、参与积极性） | （动态） | 教师/互评 | 观察/记录 |
| 学习行为 | （动态，如操作规范、协作配合、安全操作） | （动态） | 教师/学生互评 | 观察/记录/任务检查 |
| 学习效果 | （动态，如作品质量、测试成绩） | （动态） | 教师/企业导师 | 作品评分/测试 |
| 合计 | | 100分 | | |

- 至少包含学习态度、学习行为、学习效果三个维度
- 条目由 AI 根据课题动态增减（理实一体课增加"安全操作"指标等）
- 分层版含基础达标标准和进阶优秀标准；**双列分值各自加总 = 100/100（生成后验算）**

